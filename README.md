# Harri (`harrymove-ctrl.github.io`)

Personal developer site and bake log for Harri at CommandOSS, built with Vite, TypeScript, self-hosted `@fontsource` fonts, and original cobalt-on-cream SVG illustrations.

## Development

```bash
pnpm install
pnpm build
pnpm preview
```

## Customization

Edit `src/content.ts` to update profile copy, role wording, bake log notes, project links, or camera-roll cards.
